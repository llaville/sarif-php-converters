
## 1.8.0 - 2026-10-06

> [!NOTE]
> PHAR distribution included now all converters, to avoid package (converter) not installed error at runtime.

### Changed

- PHPUnit default config file (`phpunit.xml.dist`) was moved from project root folder to `.github/linters` location.

- **PHPMD converter** :

  - add support to major PHPMD stable [version 3.0](https://github.com/phpmd/phpmd/releases/tag/3.0.0)
  - SARIF `PhpMdRenderer` print either compact or pretty print JSON output

### Fixed

- Fixed the project autoloader to be compatible with PHAR distribution and
  global `_composer_autoload_path` variable defined by Composer bin proxy.

**Full Changelog**: [1.7.0...1.8.0](https://github.com/llaville/sarif-php-converters/compare/1.7.0...1.8.0)
