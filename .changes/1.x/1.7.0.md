
## 1.7.0 - 2026-09-11

### Added

- Phan major version 6 is now supported

### Changed

- **ECS version support limited** :

  Due to changes (deprecations) that came with version 13.3 of ECS (see https://github.com/ecsphp/ecs/releases#release-13.3.0),
  to avoid BC breaks, we limit support to previous version 13.2

- **Rector version support limited** :

  Due to changes (deprecations) on Rector version 2.6, to avoid BC breaks, we limit support to previous version 2.5

- `tool.driver.version` is initialized now for all converters

### Fixed

- `repositoryUri` content of `versionControlProvenance` property

**Full Changelog**: [1.6.0...1.7.0](https://github.com/llaville/sarif-php-converters/compare/1.6.0...1.7.0)
